# Репетиторий

Интерактивная веб-игра, в которой пользователь угадывает стоимость услуг репетиторов по математике на основе реальных объявлений с Авито.

## 🎮 Как играть

1. Нажмите «Запустить игру» на главной странице
2. Изучите объявление: фото, описание, город, опыт преподавателя
3. Передвиньте бегунок, чтобы выбрать предполагаемую цену занятия
4. Нажмите «Оценить» и узнайте правильную цену
5. Получите баллы за точность (максимум 100 за объявление)
6. После 10 раундов узнайте свой итоговый результат

## 📊 Система баллов

| Отклонение от реальной цены | Баллы |
|---|---|
| 0–5% | 100 |
| 5–10% | 80 |
| 10–20% | 60 |
| 20–30% | 40 |
| 30–50% | 20 |
| Более 50% | 0 |

Максимальный результат за игру — 1000 баллов.

## 🛠 Технологии

- **React 18** — UI-фреймворк
- **TypeScript** — типизация
- **Tailwind CSS 4** — стилизация
- **Vite** — сборка и dev-сервер

## 🚀 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера

# Сборка для production
```

## 📝 Обновление датасета

Данные репетиторов хранятся в `src/data/tutors.ts`. Для обновления:

1. Подготовьте CSV-файл с объявлениями
2. Нормализуйте данные в формат `Tutor`:
   - `id` — уникальный идентификатор
   - `title` — заголовок объявления
   - `description` — описание (без цен)
   - `city` — город
   - `tutorName` — имя преподавателя
   - `price` — числовая цена (без «от»)
   - `priceLabel` — оригинальное отображение цены
   - `images` — массив URL фотографий
   - `avitoUrl` — ссылка на объявление
   - `experience` — опыт (опционально)
   - `specialization` — специализация (опционально)
3. Замените массив `tutors` в `src/data/tutors.ts`

## ⚠️ Примечания

- Проект является учебным и не связан с компанией Авито
- Все цены отражают данные на момент сбора информации
- Фотографии являются нейтральными заглушками
- Мы угадываем минимальную опубликованную цену, а не достоверную стоимость часового занятия

## 📱 Адаптивность

Приложение полностью адаптировано для мобильных устройств (от 320px). Mobile-first подход обеспечивает удобство использования на смартфонах.
