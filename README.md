# Репетиторий

Интерактивная веб-игра, в которой пользователь угадывает стоимость услуг репетиторов по математике на основе реальных объявлений с Авито.

## 🎮 Как играть

1. Нажмите «Запустить игру» на главной странице
2. Изучите объявление: фотографию, заголовок, город
3. Передвиньте бегунок, чтобы выбрать предполагаемую цену занятия
4. Нажмите «Оценить» и узнайте правильную цену
5. Получите баллы за точность (максимум 100 за объявление)
6. После 10 раундов узнайте свой итоговый результат

## 📊 Система баллов

| Отклонение от реальной цены | Баллы |
|---|---|
| 0–5% | 100 |
| 5–10% | 80 |
| 10–20% | 60 |
| 20–30% | 40 |
| 30–50% | 20 |
| Более 50% | 0 |

Максимальный результат за игру — 1000 баллов.

## 📝 Источник данных

Игра использует **28 реальных объявлений** репетиторов по математике из Ленинградской области, собранных с платформы Авито. Для каждого объявления доступны:
- Заголовок объявления
- Реальная фотография из объявления
- Город
- Минимальная опубликованная цена

## 🛠 Технологии

- **React 18** — UI-фреймворк
- **TypeScript** — типизация
- **Tailwind CSS 4** — стилизация
- **Vite** — сборка и dev-сервер

## 📝 Обновление датасета

Данные репетиторов хранятся в `src/data/tutors.ts`. Массив `rawTutors` содержит объекты с полями:
- `t` — заголовок объявления
- `p` — минимальная цена в рублях
- `c` — город
- `id` — идентификатор объявления Авито

Объект `tutorImages` содержит соответствие ID → URL фотографии.

## ⚠️ Примечания

- Проект является учебным и не связан с компанией Авито
- Все цены и фотографии отражают данные на момент сбора информации
- Мы угадываем минимальную опубликованную цену, а не достоверную стоимость часового занятия
- При недоступности внешних фотографий отображается нейтральная заглушка

## 📱 Адаптивность

Приложение полностью адаптировано для мобильных устройств (от 320px). Mobile-first подход обеспечивает удобство использования на смартфонах.
